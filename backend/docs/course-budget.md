# 코스 예산과 예상 경비

- 입력한 전체 예산은 경비 유무와 별개로 생성·복원·저장 목록·상세에 표시한다.
- 생성 응답, 상세 조회, 장소 교체는 같은 예산 계산기를 사용한다.
- 착한가격업소로 지정되고 수집기가 만든 `대표메뉴:` 형식일 때만 메뉴 가격을 사용한다.
  표시된 대표메뉴 중 1인 1메뉴 × 인원수의 최소·최대를 **추정 식비**로 계산한다.
  이는 실제 주문·결제 금액이 아니다. 일반 소개글의 숫자나 AI의 예상 가격은 사용하지 않는다.
- 금액이 없거나 형식이 잘못되었거나 0·음수·정수 범위 초과이면 UNKNOWN으로 남긴다.
- 생성 시 비용 원장에 저장한다. 이미 저장된 비용은 당시의 산정 스냅숏으로 유지한다.
  이후 외부 가격 자료가 바뀌어도 기존 원장을 자동 덮어쓰지 않는다(기존 UNKNOWN도 포함).
- 비용 원장이 없는 기존 저장 코스는 현재 보유한 메뉴 자료로 읽기 전용 계산한다.
  GET 요청으로 DB를 변경하거나 코스를 재생성하지 않는다.
- 장소를 교체하면 해당 일정의 옛 비용만 삭제하고 새 장소로 다시 산정한다.
- 합계·사용률·남은 예산은 산정 가능한 항목만 기준으로 한다. 가격 미상 항목과
  미산정 숙박·교통비는 포함하지 않으며 화면에 이를 안내한다.
- 공유 응답에는 예산과 비용 내역을 추가하지 않는다. 기존 소유자 조회 권한도 유지한다.

새 예산 DB 스키마 변경이나 운영 데이터 일괄 수정은 필요하지 않다.
